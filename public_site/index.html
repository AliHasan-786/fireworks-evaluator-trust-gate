Method

Trust is a measured property of the evaluator.

  1. 01

    Ground truth first

    Exact intent and clarification behavior are checked deterministically. Parse and API errors fail visibly.

  2. 02

    Judge only the irreducible

    An LLM judge assesses whether a rationale names the real ambiguity. It cannot override ground truth.

  3. 03

    Calibrate blind

    Humans review fingerprinted raw evidence for all ambiguity cases plus failure-prone answerable cases without evaluator or judge scores.

  4. 04

    Gate on missed failures

    Agreement matters, but failure recall is first class because evaluator leniency can corrupt a reward loop.

Product implication

Make calibration a setup state, not a postmortem.

A candidate Fireworks Evaluator Trust Report would sit between evaluator creation and automation. It would expose blind human comparison, missed-failure direction, uncertainty, and explicit states such as insufficient evidence or evaluator too lenient. Customer-controlled execution remains a requirement where labels and reward logic cannot leave the environment.
